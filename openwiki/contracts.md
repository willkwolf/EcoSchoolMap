# OpenWiki - Governance Contracts Registry

This document catalogues the formal governance contracts governing the repository:

1. **[Data Governance Contract](file:///docs/contracts/DATA_GOVERNANCE_CONTRACT.md)**
   - Schema definitions, canonical descriptors, validation pipelines, and mutation rules for `data/escuelas.json`.
2. **[Visual & UI Governance Contract](file:///docs/contracts/VISUAL_AND_UI_CONTRACT.md)**
   - Mathematical coordinate mapping, 4 normalization techniques, D3 force collision invariants, Klein palette specifications, and responsive UI constraints.
3. **[Agent Governance Contract](file:///docs/contracts/AGENT_GOVERNANCE_CONTRACT.md)**
   - Operating rules for AI coding assistants, permitted/protected file scopes, obligatory testing gates, and clean Git history requirements.
4. **[JSON Schema Draft-07](file:///docs/schemas/escuelas.schema.json)**
   - Machine-verifiable data schema for node attributes, descriptors, and directed historical transitions.
