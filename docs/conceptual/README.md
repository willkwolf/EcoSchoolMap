# 📚 Marco Conceptual y Epistemológico (Conceptualization Framework)

Este directorio alberga la base teórica, historiográfica y filosófica del proyecto **Mapa de Escuelas Políticas y Económicas**.

A diferencia de los contratos de gobierno y los esquemas técnicos (que norman la estructura del código y los datos), este espacio contiene la **justificación académica del artefacto**, fundamentada en la economía pluralista y la pedagogía visual interactiva.

## 🧭 Pilares Epistemológicos

1. **Pluralismo Metodológico (Ha-Joon Chang)**:
   La economía no es una ciencia deductiva cerrada con una única doctrina axiomática, sino un campo de batalla intelectual donde múltiples marcos teóricos compiten para explicar distintos ámbitos de la realidad material.

2. **Espacio Conceptual vs. Espacio Factible**:
   El plano bidimensional visible del mapa $[-1.0, 1.0]^2$ es un *espacio conceptual* (lo que las teorías prescriben o imaginan). La viabilidad de una política, sin embargo, está acotada por el *espacio factible*, recortado por límites biofísicos termodinámicos (Georgescu-Roegen, Daly), dinamismo de sistemas con retardos (Meadows) y redes no lineales de complejidad (CAS, Arthur, Farmer).

3. **La Regla de Consistencia de Nodos**:
   Una teoría económica se proyecta como un **nodo/punto decisional** en el mapa si y solo si define simultáneamente un mecanismo institucional de coordinación (Eje X) y una función objetivo socioeconómica (Eje Y). Si actúa como restricción que condiciona a todas las escuelas, es una **capa transversal**, no un punto.

4. **Cartografía como Reducción Dimensional**:
   El mapa opera de forma análoga a un *embedding* dimensional: colapsa la riqueza multifacética de las Weltanschauungen económicas a dos tensiones maestras para facilitar la navegación pedagógica y el pensamiento crítico.
